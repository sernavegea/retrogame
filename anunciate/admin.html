Espacios de Asfalto Rojo

Solo para ti: aquí ves los espacios, pones precios y subes los anuncios. Lo que publiques se ve en la página de anunciantes y en el juego en uno o dos minutos.

Conexión con GitHub

Sin conectar: puedes mirar y preparar cambios, pero para publicarlos hace falta la clave.

Cómo sacar la clave (una sola vez)
  1. En GitHub, entra en tu foto › Settings › Developer settings › Personal access tokens › Fine-grained tokens › Generate new token.
  2. Nombre: «Anuncios Asfalto Rojo». Caducidad: la que quieras (por ejemplo, 1 año).
  3. Repository access: «Only select repositories» y elige sernavegea/retrogame.
  4. Permissions › Repository permissions › Contents: «Read and write». Nada más.
  5. Pulsa Generate token, copia la clave (empieza por github_pat_) y pégala aquí arriba.

La clave se guarda solo en este navegador. No la compartas: con ella se puede cambiar tu web. Si la pierdes o crees que la ha visto alguien, bórrala en GitHub y crea otra.
