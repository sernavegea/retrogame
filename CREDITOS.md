# Juegos libres incluidos

Estos juegos son homebrew (hechos por aficionados) y sus autores permiten redistribuirlos. Los archivos proceden del proyecto retrobrews (github.com/retrobrews).

|---|---|---|---|
| Super Tilt Bro. (versión NESDev 2016) | NES | Sylvain Gadrat | WTFPL |
| Double Action Blaster Guys | NES | NovaSquirrel | zlib |
| Nova the Squirrel | NES | NovaSquirrel | Código GPL-3.0, gráficos y niveles CC BY-NC-SA 4.0 |
| µCity | Game Boy Color | Antonio Niño Díaz | Código GPL-3.0, gráficos CC BY-SA 4.0 |

Código fuente:
- Super Tilt Bro.: https://github.com/sgadrat/super-tilt-bro
